# AI 응답 근거 제한 규칙 v5 적용 결과

## 1. 측정 목적

`ai-chat-v4`는 근거 없는 방문 가능 여부 단정을 제거했지만, 판단에 필요한 기존 일정과 부족한 정보를 함께 알려주지 않았다. `ai-chat-v5`에서는 판단할 수 없다는 결론 전에 관련 일정의 시작 시간과 부족한 정보를 안내하도록 보완하고, 고정 평가셋 12건으로 토큰과 답변 품질을 다시 확인한다.

공식 원본 결과는 평가 실행기가 자동 생성한 [response-policy-v5-95f7fa4.json](../artifacts/response-policy-v5-95f7fa4.json)에 보존한다.

## 2. 변경 내용

`ai-chat-v5`에서는 다음 규칙을 변경했다.

```text
종료 시간, 체류 시간 또는 이동 시간이 없어 판단할 수 없다면
관련 일정의 시작 시간과 부족한 정보를 안내한 뒤,
확정적으로 판단할 수 없다고 답한다.
```

이번 단계에서도 일정 조회 범위와 이전 대화 범위는 변경하지 않았다. 따라서 측정 결과를 일정 필터링이나 최근 대화 윈도우의 효과로 해석하지 않는다.

### 5.1 시간 제약 답변 개선

`ai-chat-v5`는 관련 일정과 판단에 부족한 정보를 함께 안내했다.

> 12시 30분에 토속촌 삼계탕 방문이 시작되고, 15시 00분에 국립민속박물관 방문이 시작됩니다. 두 일정 사이에 13시 광화문광장 방문 가능 여부는 각 일정의 체류 시간 정보가 없어 확정적으로 판단할 수 없습니다.

v4에서 누락됐던 두 일정의 시작 시간을 제공했고, 근거 없는 방문 가능 여부를 생성하지 않았다. 다만 고정 평가셋의 `requiredFacts`에 포함된 이동 시간 정보 부족은 직접 언급하지 않았다. 일정 사실, 언어, 근거 없는 정보 생성 방지의 수동 루브릭은 충족했지만, 고정 평가셋의 기대 사실을 완전히 충족한 것으로 확대 해석하지 않는다.

### 5.2 정보 부족 질문의 회귀

항공편 예약번호 질문에는 다음과 같이 답했다.

> 2026-08-20 09시 00분에 시작하는 일정에 대한 항공편 예약번호는 제공되지 않아 확인할 수 없습니다.

예약번호가 제공되지 않았다는 결론은 정확하지만, 항공편 예약번호를 경복궁 방문이 시작되는 09시 일정에 연결할 근거는 없다. 시간 제약 답변을 보완하기 위해 추가한 "관련 일정의 시작 시간 안내" 규칙이 일반적인 정보 부족 질문에도 적용된 것으로 판단한다.

## 7. 결론과 후속 가설

`ai-chat-v5`에서 확인한 결과는 다음과 같다.

- 시간 제약 질문에서 관련 일정과 부족한 정보를 안내해 v4의 정보 누락을 보완했다.
- 근거 없는 방문 가능 여부 단정을 생성하지 않았다.
- 선호 전달 응답의 간결성과 장기 기억 회상을 유지했다.
- 관련 일정 안내 규칙이 항공편 예약번호 질문까지 적용돼 새로운 근거 없는 연결을 만들었다.
- v4 대비 전체 토큰이 5.83% 증가했으며 최초 기준선 대비 절감률은 1.44%였다.

후속 프롬프트에서는 관련 일정 안내 규칙을 모든 정보 부족 질문에 적용하지 않고, 일정 사이의 여유 시간이나 방문 가능 여부를 묻는 경우로 범위를 제한한다.

```text
일정 사이의 여유 시간이나 방문 가능 여부를 묻는 경우에만,
전후 일정의 시작 시간과 누락된 종료·체류·이동 시간 정보를 모두 안내한 뒤
확정적으로 판단할 수 없다고 답한다.
```

이 범위 보정은 일정 조회 범위 제한과 섞지 않고 별도 프롬프트 버전으로 측정한다.

## 8. 측정 한계

- 모델 옵션이 provider default이며 각 질문을 한 번씩 실행한 결과다.
- 모델 응답의 비결정성 때문에 토큰 변화 전체를 프롬프트 문구만의 효과로 단정할 수 없다.
- 품질 점수는 고정 루브릭에 따른 수동 채점 결과다.
- 고정 루브릭 점수와 질문별 `requiredFacts` 충족 여부를 함께 확인해야 한다.
- 현재 시간이 프롬프트에 포함되므로 이전 측정과 프롬프트 바이트가 완전히 동일하지 않다.
- `completionTokens`에는 사용자에게 보이지 않는 내부 추론 토큰이 포함될 수 있다.
- `serviceDurationMs`는 HTTP 왕복 시간이나 사용자 체감 TTFT가 아니다.
