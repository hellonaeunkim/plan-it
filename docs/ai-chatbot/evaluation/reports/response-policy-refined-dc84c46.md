# AI 응답 근거 제한 규칙 v4 적용 결과

## 1. 측정 목적

`ai-chat-v3`에서 일반적인 추측 금지 규칙을 적용했지만, 모델이 두 일정의 방문 시작 시간 차이를 여유 시간으로 해석하고 방문 가능 여부를 단정했다. `ai-chat-v4`에서는 일정 데이터의 의미와 선호 전달 메시지의 응답 방식을 구체화하고, 고정 평가셋 12건으로 토큰과 답변 품질을 다시 확인한다.

공식 원본 결과는 평가 실행기가 자동 생성한 [response-policy-refined-dc84c46.json](../artifacts/response-policy-refined-dc84c46.json)에 보존한다.

토큰과 응답 원문은 평가 실행기가 자동 저장했고, 이 Markdown의 품질 판정과 설명은 평가 당시 적용한 기준에 따라 Codex가 응답 원문을 보조 검토해 작성했다. 평가에 사용한 Codex 모델·지시문·버전은 산출물에 기록되지 않아 정식 LLM-as-a-Judge 결과가 아닌 참고 자료로 취급한다.

## 2. 변경 내용

`ai-chat-v4`에서는 다음 규칙을 적용했다.

- 일정의 방문 시간은 시작 시간이며 종료 시간이나 체류 시간을 의미하지 않음
- 종료 시간, 체류 시간, 이동 시간이 없으면 일정 사이의 여유 시간이나 방문 가능 여부를 판단하지 않음
- 제공된 데이터에 없는 사실이나 실행하지 않은 일정 변경 결과를 생성하지 않음
- 사용자가 선호나 제약만 전달하면 추가 조언 없이 한 문장으로 확인
- 질문에 직접 답하고 요청하지 않은 설명, 표, 대안을 제한

이번 단계에서도 일정 조회 범위와 이전 대화 범위는 변경하지 않았다. 따라서 측정 결과를 일정 필터링이나 최근 대화 윈도우의 효과로 해석하지 않는다.

### 5.1 시간 제약 답변 변화

`ai-chat-v3`는 시작 시간 사이를 실제 여유 시간으로 해석했다.

> 12:30~15:00 사이에 약 2시간 30분의 여유가 있습니다. 따라서 오후 1시에 방문하는 것은 충분히 가능한 시간대입니다.

`ai-chat-v4`는 근거 없는 가능 여부 단정을 제거했다.

> 일정 사이의 여유 시간을 판단할 수 없습니다.

환각 방지 목표는 달성했지만, 고정 평가셋이 요구하는 다음 사실을 함께 안내하지 않았다.

- 12:30 토속촌 삼계탕
- 15:00 국립민속박물관
- 종료·체류·이동 시간이 없어 확정적으로 판단할 수 없음

즉, 안전한 답변으로 바뀌었지만 사용자가 판단에 필요한 알려진 사실까지 생략해 유용성이 낮아졌다.

짧아진 답변이 다음 요청의 이전 대화로 다시 포함되면서 두 번째 턴 입력은 `1,309`에서 `905`로 감소했다. 첫 턴 대비 마지막 턴 입력 증가율도 `66.37%`에서 `19.54%`로 46.83%p 낮아졌다.

전체 이전 대화를 계속 전달하는 구조는 유지되고 있으므로 대화가 길어지면 입력 토큰은 계속 증가한다. 이번 결과는 최근 대화 윈도우나 누적 요약의 효과가 아니다.

## 7. 결론과 후속 가설

`ai-chat-v4`에서 확인한 결과는 다음과 같다.

- 시간 제약 질문의 근거 없는 방문 가능 여부 단정을 제거했다.
- 선호만 전달한 메시지의 장문 응답을 한 문장으로 제한했다.
- 선호 전달 답변이 짧아지면서 장기 대화의 첫 턴 대비 마지막 턴 입력 증가율이 v3 `66.37%`에서 v4 `19.54%`로 낮아졌다.
- 한 차례 평가에서 전체 토큰은 v3보다 14.23%, 최초 기준선보다 6.87% 낮게 측정됐지만 이를 반복 측정한 절감률로 사용하지 않는다.
- 시간 제약 답변에서 알려진 일정과 부족한 정보가 누락된 사례를 확인했다.

다음 보완에서는 판단을 금지하는 데서 끝내지 않고, 판단 근거가 부족한 경우에도 알려진 사실을 먼저 제공하도록 규칙을 구체화한다.

```text
판단에 필요한 정보가 부족하면 관련 일정의 시작 시간과 부족한 정보를 함께 안내한 뒤,
확정적으로 판단할 수 없다고 답한다.
```

이 변경은 일정 조회 범위 제한과 섞지 않고 별도 프롬프트 버전으로 측정한다.

## 8. 측정 한계

- 모델 옵션이 provider default이며 각 질문을 한 번씩 실행한 결과다.
- 모델 응답의 비결정성 때문에 토큰 변화 전체를 프롬프트 문구만의 효과로 단정할 수 없다.
- 품질 판정은 평가 당시 적용한 기준에 따라 Codex가 응답 원문을 보조 검토한 참고 기록이다.
- 현재 시간이 프롬프트에 포함되므로 이전 측정과 프롬프트 바이트가 완전히 동일하지 않다.
- `completionTokens`에는 사용자에게 보이지 않는 내부 추론 토큰이 포함될 수 있다.
- `serviceDurationMs`는 HTTP 왕복 시간이나 사용자 체감 TTFT가 아니다.
