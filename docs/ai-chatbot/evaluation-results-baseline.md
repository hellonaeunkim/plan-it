# AI 챗봇 기준선 평가 결과

## 1. 측정 목적

현재 구현인 `전체 일정 + 전체 대화` 방식의 토큰 사용량과 답변 품질을 측정한다. 이 문서에는 측정으로 확인한 사실만 기록하며, 이후 적용할 개선 방법이나 예상 결과를 미리 결론 내리지 않는다.

## 3. 실행 조건

- 독립 질문 6개는 동일한 사용자와 일정 fixture를 사용하되, 질문마다 대화 이력이 비어 있는 새로운 채팅방에서 실행한다.
- 장기 기억 시나리오는 하나의 채팅방에서 정해진 턴 순서대로 실행한다.
- 각 요청 직후 `ai_chat_response_metric` 로그와 LLM 원문 답변을 저장한다.
- 실패한 요청을 성공 결과로 대체하지 않고 실패 유형, 시도 횟수와 재실행 여부를 기록한다.
- 같은 채팅방에 요청을 동시에 전송하지 않는다.

## 9. 측정 한계

- `serviceDurationMs`는 서비스 메서드 내부 시간이며 HTTP 왕복 시간이나 TTFT가 아니다.
- 현재 외부 LLM 호출은 DB 트랜잭션 안에서 실행된다. 따라서 이번에는 동시 요청이나 부하 테스트를 수행하지 않는다.
- LLM 응답은 같은 입력에서도 달라질 수 있으므로 원문 답변과 측정 횟수를 함께 해석한다.
